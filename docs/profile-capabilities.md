# Reference capability map

The supplied recording and image are references for capabilities, not profile
content or templates. No reference video, photo, music or branding is shipped.

| Visible feature | Where to configure it |
| --- | --- |
| Full-screen moving background (recording 0-10s, 18-44s) | Account / Profile / Background: Video, direct URL or short upload; saturation, contrast, brightness, dim and blur |
| Centred outer card, with left/centred contents or separate stacked widgets | Customize / Card: Layout; Stacked places widget cards and audio below the profile |
| Clear, dark glass or compact cards | Customize / Card: composition, opacity, padding, radius and card style |
| Centred identity or left-avatar identity | Customize / Card: page layout, avatar placement and name/bio alignment |
| Glowing social icons | Links: icon colour, size and glow |
| Entry image/GIF and transition (14-18s) | Customize / Entry screen: image upload/URL, image size and entry animation |
| Pointer point, ring or red comet trail | Customize / Effects: cursor and trail preview galleries |
| Click sound and click ripple | Customize / Effects: built-in sounds or your own short audio clip; volume and all-clicks option |
| Audio inside/below the card, pinned to the bottom or Popup at top left | Customize / Card: music placement; Customize / Music: track, cover, playback, popup appearance and lyrics |
| Twinkling stars around the name | Customize / Effects: Display name / Sparkle; adjust density, strength, duration and font |
| Moving border beams and other card lighting | Customize / Effects: Card lighting gallery |
| Dotted overlay | Customize / Effects: Overlay gallery: Dotted and opacity |
| About content and project cards (30-44s) | Customize / Card: Profile sections; add, reorder and edit your own text, artwork and links |
| Matching typography | Profile font picker, custom font upload, and per-target text-effect fonts |

All choices are part of the saved profile document. Effects previews use small
black-backed gallery tiles grouped into tabs; static posters come from the real
background engines, which animate only on hovered thumbnails. Overlays have a
dedicated finish catalogue rather than duplicating particle backgrounds. Public pages use
the same effect layers. Exact visual matching still requires the original media,
font files, icon artwork and settings, supplied by the profile owner.

Audio uploads use separate chunked storage and have no application-level size or
duration limit. Hosted audio URLs are also supported. Large videos can use direct
hosted media URLs; embedded video uploads share the profile document size limit.

Popup audio is a circular music icon. Hover it or focus it with the keyboard to
reveal the volume rail beside it. On touchscreens, tapping focuses the control.
Music settings include corner, spacing, icon size/colour, background, opacity,
rail width, reveal duration, default volume, mute, loop and playback speed.

Card settings no longer contain a live preview. Stacked cards can share one
pointer tilt when “Tilt stacked cards together” is on. Profile sections use
normal vertical scrolling; adding a section does not enable a slideshow,
screen snapping, or an automatic scrolling timer.
